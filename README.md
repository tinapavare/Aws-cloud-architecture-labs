## 📌 Sobre el proyecto

Este repositorio documenta mi recorrido en el **Bootcamp de AWS Cloud Computing de BeTek**. Aquí reúno los laboratorios prácticos, los diseños de arquitectura y las evidencias de cada evaluación, con el fin de:

- Dejar registro del progreso técnico a lo largo del bootcamp.
- Servir como portafolio de habilidades en la nube.
- Funcionar como material de consulta para futuros proyectos.

---

## 🎯 Objetivos de aprendizaje

- Comprender los fundamentos de la computación en la nube y la infraestructura global de AWS.
- Diseñar y desplegar arquitecturas seguras, escalables y de alta disponibilidad.
- Gestionar identidades y permisos aplicando el principio de mínimo privilegio.
- Aplicar buenas prácticas del **AWS Well-Architected Framework**.
- Optimizar costos y monitorear recursos en la nube.
